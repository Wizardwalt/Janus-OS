3. Download your Janus archive

The archive contains the untouched source files, a normalized JSON index, one readable Markdown file per conversation, and a master index. Duplicate conversation IDs are indexed once; all original source files remain included.

What is included?
  • originals/ — original JSON files and original ZIP files, unchanged.
  • janus-arena-archive.json — normalized conversation records with original record data retained.
  • conversations/ — readable Markdown transcripts.
  • INDEX.md — chronological conversation index.
  • manifest.json — import counts, source filenames, duplicate counts, and warnings.
